1. Principios del tratamiento de datos

SalahTrack está diseñada principalmente como una aplicación de oración que funciona de forma local. Actualmente no existe una cuenta de usuario de SalahTrack ni un servidor propio de SalahTrack al que se suba el historial de oraciones o de Ramadán. Gran parte de los datos de la aplicación se almacena únicamente en el dispositivo.

Para determinadas funciones, en especial el cálculo de los horarios de oración y la búsqueda de ubicaciones, pueden transmitirse datos a servicios externos según se describe a continuación.

2. Datos de ubicación

Si se activa la ubicación automática, SalahTrack puede utilizar una ubicación aproximada o precisa para mostrar los horarios de oración y la dirección de la alquibla. El acceso a la ubicación es opcional; también se puede elegir una ubicación manualmente. Las coordenadas, la ciudad, el país, la zona horaria y el modo de ubicación seleccionado pueden almacenarse localmente. La versión aquí descrita no solicita acceso permanente a la ubicación en segundo plano.

3. Horarios de oración y API de AlAdhan

Para calcular u obtener los horarios de oración, SalahTrack utiliza AlAdhan a través de api.aladhan.com. Pueden transmitirse por HTTPS la latitud y la longitud, así como parámetros de cálculo como el mes, el año, el método de cálculo, la escuela jurídica para el Asr y las reglas para latitudes altas. Los proveedores de red y el servicio reciben necesariamente datos de conexión, como la dirección IP. En la implementación aquí descrita, SalahTrack no transmite ningún identificador de usuario de SalahTrack, identificador publicitario ni identificador de dispositivo generado por la aplicación.

4. Geocodificación y búsqueda manual de ubicaciones

Cuando se busca manualmente una ubicación, se solicitan sugerencias o se convierten coordenadas en el nombre de un lugar, los servicios de geocodificación pueden procesar datos del lugar o coordenadas. Según el dispositivo y la implementación, pueden intervenir proveedores de plataforma o del sistema, como Apple o Google.

5. Datos almacenados localmente

Según el uso, pueden almacenarse en el dispositivo los horarios de oración y calendarios en caché, el estado de las oraciones y las horas de confirmación o recordatorio, las actividades de Ramadán, la configuración de ubicación y cálculo, el idioma, el diseño, la configuración de notificaciones y otros estados locales de la aplicación. El historial de oraciones y de Ramadán puede revelar prácticas religiosas y, en la implementación aquí descrita, no se sube a ningún servidor de SalahTrack.

6. Alquibla y brújula

La dirección de la alquibla se calcula mediante los datos de ubicación. Las lecturas de la brújula pueden utilizarse para mostrar la dirección en pantalla y, en la implementación aquí descrita, no se almacenan de forma permanente ni se transmiten a ningún servidor de SalahTrack.

7. Notificaciones

SalahTrack puede programar notificaciones locales para las oraciones, recordatorios, aplazamientos, la oración del viernes y funciones de Ramadán. Los datos de las notificaciones se gestionan localmente mediante la aplicación y el sistema operativo. La versión aquí descrita no utiliza un servidor propio de notificaciones push remotas ni una infraestructura de tokens push de SalahTrack.

8. Análisis, publicidad y seguimiento

La versión aquí descrita no utiliza publicidad, seguimiento, análisis ni SDK de informes de fallos como Google Mobile Ads, Firebase Analytics, Crashlytics, Meta, AppsFlyer, Adjust, Amplitude, Mixpanel o Sentry, ni utiliza un identificador publicitario para rastrear a los usuarios.

9. Informar de un problema y asistencia por correo electrónico

La función «Informar de un problema» permite elegir una categoría, describir un problema e indicar opcionalmente los pasos para reproducirlo. SalahTrack prepara información técnica no sensible, como la versión de la aplicación, el número de compilación, la plataforma, la versión del sistema operativo, el modelo del dispositivo y el idioma de la aplicación. Esta información se muestra antes del envío. No se envía nada automáticamente: se abre la aplicación de correo electrónico del usuario con un informe preparado que puede revisarse, editarse, cancelarse o enviarse expresamente. No se adjuntan automáticamente la ubicación GPS exacta, el historial de oraciones o de Ramadán, la actividad religiosa personal, identificadores publicitarios ni identificadores únicos del dispositivo. Si se envía, el informe se procesa a través del proveedor de correo electrónico del usuario y se entrega a ar830222@gmail.com; también se aplican las condiciones de privacidad de dicho proveedor.

10. Reseñas dentro de la aplicación

SalahTrack puede abrir la interfaz del sistema de Apple o Google para valorar la aplicación. En ese caso pueden contactarse los servicios habituales de la tienda; SalahTrack no recibe directamente el contenido de la reseña mediante esta función.

11. Conservación y eliminación

En la versión aquí descrita, los datos de oración y de Ramadán almacenados localmente no tienen un plazo general de conservación automática. Los datos locales de la aplicación pueden eliminarse desinstalando la aplicación o, si el sistema operativo lo permite, borrando sus datos.

12. Seguridad de los datos

Las solicitudes de red a AlAdhan para obtener horarios de oración utilizan HTTPS. Los datos locales se almacenan en el entorno aislado de la aplicación proporcionado por el sistema operativo. La implementación aquí descrita no añade cifrado en el nivel de la aplicación a SQLite ni a SharedPreferences.

13. Permisos

SalahTrack solicita los permisos necesarios para las funciones activadas, en especial los de ubicación y notificaciones. Los permisos pueden revocarse en los ajustes del sistema de iOS o Android; en ese caso, algunas funciones pueden quedar limitadas.

14. Sus derechos de protección de datos

Cuando resulte aplicable la legislación de protección de datos, usted puede tener derechos de acceso, rectificación, supresión, limitación, portabilidad de los datos y oposición, así como el derecho a retirar su consentimiento con efecto futuro. Las solicitudes relativas a la privacidad pueden enviarse a ar830222@gmail.com. También puede tener derecho a presentar una reclamación ante una autoridad de control competente.

15. Cambios en esta política

Esta política se actualizará cuando cambien las funciones, los servicios, los permisos o los flujos de datos de SalahTrack. La versión vigente se publica en esta página.
