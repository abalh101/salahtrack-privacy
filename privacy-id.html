1. Prinsip pemrosesan data

SalahTrack terutama dirancang sebagai aplikasi salat yang bekerja secara lokal. Saat ini tidak ada akun pengguna SalahTrack maupun server SalahTrack tempat riwayat salat atau Ramadan diunggah. Sebagian besar data aplikasi hanya disimpan di perangkat.

Untuk fungsi tertentu, terutama penghitungan waktu salat dan pencarian lokasi, data dapat dikirimkan ke layanan eksternal sebagaimana dijelaskan di bawah ini.

2. Data lokasi

Jika lokasi otomatis diaktifkan, SalahTrack dapat menggunakan lokasi perkiraan atau lokasi akurat untuk menyediakan waktu salat dan arah kiblat. Akses lokasi bersifat opsional; lokasi juga dapat dipilih secara manual. Koordinat, kota, negara, zona waktu, dan mode lokasi yang dipilih dapat disimpan secara lokal. Versi yang dijelaskan di sini tidak meminta akses lokasi latar belakang secara permanen.

3. Waktu salat dan API AlAdhan

Untuk menghitung atau mengambil waktu salat, SalahTrack menggunakan AlAdhan melalui api.aladhan.com. Garis lintang dan bujur serta parameter penghitungan seperti bulan, tahun, metode penghitungan, mazhab Asar, dan aturan lintang tinggi dapat dikirimkan melalui HTTPS. Penyedia jaringan dan layanan tersebut secara teknis menerima data koneksi seperti alamat IP. Dalam implementasi yang dijelaskan di sini, SalahTrack tidak mengirimkan ID pengguna SalahTrack, ID iklan, atau ID perangkat yang dibuat oleh aplikasi.

4. Geocoding dan pencarian lokasi manual

Saat lokasi dicari secara manual, saran diminta, atau koordinat diubah menjadi nama tempat, informasi tempat atau koordinat dapat diproses oleh layanan geocoding. Bergantung pada perangkat dan implementasinya, penyedia platform atau sistem seperti Apple atau Google dapat terlibat.

5. Data yang disimpan secara lokal

Bergantung pada penggunaan, perangkat dapat menyimpan waktu salat dan jadwal dalam cache, status salat serta waktu konfirmasi/pengingat, aktivitas Ramadan, pengaturan lokasi dan penghitungan, bahasa, tampilan, pengaturan notifikasi, dan status aplikasi lokal lainnya. Riwayat salat dan Ramadan dapat mengungkapkan praktik keagamaan dan, dalam implementasi yang dijelaskan di sini, tidak diunggah ke server SalahTrack.

6. Kiblat dan kompas

Arah kiblat dihitung menggunakan data lokasi. Pembacaan kompas dapat digunakan untuk menampilkan arah di layar dan, dalam implementasi yang dijelaskan di sini, tidak disimpan secara permanen atau dikirimkan ke server SalahTrack.

7. Notifikasi

SalahTrack dapat menjadwalkan notifikasi lokal untuk salat, pengingat, penundaan, salat Jumat, dan fungsi Ramadan. Data notifikasi dikelola secara lokal oleh aplikasi dan sistem operasi. Versi yang dijelaskan di sini tidak menggunakan server push jarak jauh SalahTrack maupun infrastruktur token push.

8. Analitik, iklan, dan pelacakan

Versi yang dijelaskan di sini tidak menggunakan SDK iklan, pelacakan, analitik, atau pelaporan kerusakan seperti Google Mobile Ads, Firebase Analytics, Crashlytics, Meta, AppsFlyer, Adjust, Amplitude, Mixpanel, atau Sentry, dan tidak menggunakan ID iklan untuk melacak pengguna.

9. Melaporkan masalah dan dukungan melalui email

Fitur “Laporkan masalah” memungkinkan pengguna memilih kategori, menjelaskan masalah, dan secara opsional memberikan langkah untuk mereproduksinya. SalahTrack menyiapkan informasi teknis yang tidak sensitif seperti versi aplikasi, nomor build, platform, versi sistem operasi, model perangkat, dan bahasa aplikasi. Informasi ini ditampilkan sebelum dikirim. Tidak ada yang dikirim secara otomatis: aplikasi email pengguna dibuka dengan laporan yang telah disiapkan, yang dapat ditinjau, diedit, dibatalkan, atau dikirim secara tegas oleh pengguna. Lokasi GPS yang akurat, riwayat salat atau Ramadan, aktivitas keagamaan pribadi, ID iklan, dan pengenal perangkat unik tidak dilampirkan secara otomatis. Jika dikirim, laporan diproses melalui penyedia email pengguna dan dikirimkan ke ar830222@gmail.com; ketentuan privasi penyedia tersebut juga berlaku.

10. Ulasan dalam aplikasi

SalahTrack dapat membuka antarmuka sistem Apple atau Google untuk ulasan aplikasi. Layanan toko aplikasi yang biasa dapat dihubungi; SalahTrack tidak menerima isi ulasan secara langsung melalui fitur ini.

11. Penyimpanan dan penghapusan

Dalam versi yang dijelaskan di sini, data salat dan Ramadan yang disimpan secara lokal tidak memiliki jangka waktu penyimpanan otomatis yang berlaku umum. Data aplikasi lokal dapat dihapus dengan menghapus aplikasi atau, jika didukung sistem operasi, membersihkan data aplikasinya.

12. Keamanan data

Permintaan jaringan ke AlAdhan untuk waktu salat menggunakan HTTPS. Data lokal disimpan di sandbox aplikasi milik sistem operasi. Implementasi yang dijelaskan di sini tidak menambahkan enkripsi tingkat aplikasi pada SQLite atau SharedPreferences.

13. Izin

SalahTrack meminta izin yang diperlukan untuk fungsi yang diaktifkan, khususnya lokasi dan notifikasi. Izin dapat dicabut melalui pengaturan sistem iOS atau Android; beberapa fungsi kemudian dapat menjadi terbatas.

14. Hak perlindungan data Anda

Jika berlaku berdasarkan hukum perlindungan data, Anda mungkin memiliki hak yang mencakup akses, perbaikan, penghapusan, pembatasan, portabilitas data, dan keberatan, serta hak untuk menarik persetujuan untuk masa mendatang. Permintaan terkait privasi dapat dikirimkan ke ar830222@gmail.com. Anda juga mungkin berhak mengajukan keluhan kepada otoritas pengawas yang berwenang.

15. Perubahan pada kebijakan ini

Kebijakan ini akan diperbarui jika fungsi, layanan, izin, atau aliran data SalahTrack berubah. Versi terkini diterbitkan di halaman ini.
